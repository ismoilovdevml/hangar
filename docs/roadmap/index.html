Project

Roadmap

Each milestone ends with: green make test lint e2e, updated api/openapi.yaml, a short docs/changelog.md entry, and a ticked demo checklist.

Status as of v0.1.9 (2026-11-20) and the work in progress for v0.2.0 (see the changelog): done (shipped and covered by tests), partial (shipped with the gaps named), in progress (being built for the next release, not shipped) or planned (not implemented; API operations for it are marked x-status: planned in api/openapi.yaml and answer 501).

Releases so far#

Release Date Main content
v0.1.0 2026-11-04 First release: multi-arch image on ghcr.io, binaries with SHA256SUMS, the compose installer; web UI with packages, search and blob stores.

v0.1.2 – v0.1.5 2026-11-04 – 2026-11-05 Cluster-wide Overview traffic, System status, README images, the public OpenAPI document and automation guide.

v0.1.7 2026-11-09 Routing rules against dependency confusion; cluster operations (job stream replicas, migration lock, /metrics authentication); npm audit answered for real.
v0.1.8 2026-11-15 Local times across the web UI and many UI fixes; releases run the test suite before publishing.
v0.1.9 2026-11-20 Security and reliability: SSRF through repository proxies, sealed secret replay, NuGet proxy cache poisoning, archive bombs; the chart defaults to the release's images.
v0.2.0 2026-11-21 NATS removed (PostgreSQL events and jobs), webhooks, CI OIDC trusted publishing, hangar apply, hgs2 secrets, trigram search, signed releases and the OCI chart.

v0.2.0 (2026-11-21)#

Item Status Notes
Remove NATS Done Events on PostgreSQL LISTEN/NOTIFY, jobs in a jobs table (ADR 0011).
Webhooks Done Generic JSON, Slack and Teams, HMAC-signed, from a PostgreSQL outbox (guide).
CI OIDC token exchange Done GitHub Actions, GitLab CI and other OIDC issuers trade their ID token for a short-lived scoped token (guide).
Config as code (hangar apply) Done hangar apply, diff and export (guide).
hgs2 sealed secrets Done Sealed values are bound to their row and field (ADR 0010).
Search with pg_trgm Done One statement per search, trigram index for substrings.
Release supply chain Done cosign signatures, SPDX SBOMs and SLSA provenance for the images, the chart and the release files; the Helm chart on oci://ghcr.io/ismoilovdevml/charts/hangar; Trivy, govulncheck and npm audit gate the release (verify a release).

Notes for v0.2.0 items describe the goal; the changelog describes what actually ships.

Item by item#

Item Status Notes
Multi-node (HA) Done Stateless nodes, PostgreSQL advisory-lock leader, job queue and events in PostgreSQL; high availability.
Edge replication Planned /api/v1/replication/targets answers 501; the web UI's replication placeholder was removed in v0.1.9.
On-disk blob cache per node Planned Nodes keep only in-memory caches today.
Image scanning (Trivy) Done Optional scan adapter; vulnerabilities.
Package scanning (OSV) Done npm, Maven, PyPI, NuGet, Go, Cargo, APT and RPM.
Quarantine Done Docker images and scanned packages.
Routing rules (dependency confusion) Done Since v0.1.7; routing rules.
Cosign signatures Partial Signatures are stored and served like any other OCI artifact, so cosign sign and cosign verify work against Hangar (an e2e test covers it when cosign is installed); Hangar itself does not verify signatures or require them by policy.
Licence policy Planned
OIDC and LDAP / Active Directory Done SSO guide.
SAML Planned The sign-in page reports it as not configured.
Component SBOM download Planned GET /components/{id}/sbom answers 501.
Component dependents Planned GET /components/{id}/dependents answers 501.
Moving repositories between blob stores Planned POST /blob-stores/{name}/move-repositories answers 501.
Search reindex task Planned reindex is a reserved task type.
Scheduled database backup Planned Use deploy/scripts/backup.sh (backup and restore).
Config as code (hangar apply -f, hangar diff, hangar export) Done (0.2.0) guides/config-as-code.md. Users, tokens, tasks and sign-in providers are not managed yet.
Terraform provider Planned
Dark theme Planned Tokens only (web/src/styles/tokens.css).
